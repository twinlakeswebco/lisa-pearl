# Lisa Pearl for Clarkson Mayor

Four-page campaign preview: Home, About, Contact, Donate. Built with Next.js and React.

`npm run dev` starts the preview. `npm run build`, `npm run lint`, and `npm run typecheck` verify it. With the site running, `npm test` checks public routes and content.

All pages include the preview watermark and noindex metadata. Donate opens an email for contribution instructions; no payment processor is connected. Before launch, approve copy, confirm campaign disclaimer and contribution details, set the production domain, and remove preview branding/noindex when approved.
